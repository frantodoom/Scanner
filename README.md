# Scanner
Seminární projekt do Informatiky. Jedná se o síťový scanner, který bude mít vícero funkcí, jako je port scanner nebo ip scanner. 

Postup spouštění:
1) Stáhněte python (https://www.python.org/downloads/)
2) Stáhněte PySide přes terminál: pip3 install pyside6
3) V konzoli spuštěné ve složce, kde se nachází projekt, zadejte příkaz: python3 main.py run
